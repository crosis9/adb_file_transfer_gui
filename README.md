# ADB Command Builder

Windows上で `adb push` 用のPowerShellコマンドを生成する軽量ツールです。

## バージョン

- v0.3.2


## v0.3.2 修正内容

- `ADB接続キャッシュクリア` ボタンを追加しました。
- アプリ上の端末選択リストと選択中Deviceをクリアし、`adb kill-server` を実行します。
- Windows OS側のドライバ/デバイス履歴は削除しません。安全性を優先し、ADBサーバー状態のリセットに留めています。

## v0.3.1 修正内容

- `.ps1` 保存時にファイル名候補を自動入力するようにしました。
- Android側ディレクトリを目視判断できる軽量ファイラー表示を追加しました。
- コマンド生成、コピー、保存の完了状態をステータス表示するようにしました。
- Android側ディレクトリ候補は、ストレージ候補検出ごとにクリアして再生成するようにしました。
- ディレクトリ候補履歴を手動クリアできるボタンを追加しました。

## v0.3.0 以降の方針

安定性と軽量性を優先し、GUI内で直接ADB転送を実行する方式をやめました。

代わりに、GUIでは以下だけを行います。

- 転送元ファイルの指定
- Android側保存先ディレクトリの指定
- 接続端末IDの選択
- PowerShell用ADBコマンドの生成
- 生成コマンドのクリップボードコピー

転送自体は、生成されたPowerShellコマンドを貼り付けて実行します。

## 主な機能

- ファイルのドラッグ&ドロップ指定
- 参照ボタンからの複数ファイル選択
- 選択ファイル一覧表示
- `adb devices -l` による端末検出
- Android側保存先ディレクトリの入力・履歴保存
- Android側ディレクトリの軽量ファイラー表示
- `/storage` 配下のストレージ候補検出
- 非ASCIIファイル名向けの一時ASCII名転送
- 転送成功後にAndroid側で元の日本語ファイル名へ `mv`
- PowerShellコマンドの生成
- クリップボードコピー
- `.ps1` 保存

## 必要なもの

- Windows 10 / 11
- Python 3.11 以降推奨
- Android SDK Platform-Tools for Windows

## Platform-Tools の配置

このリポジトリには `adb.exe` やDLLは含めません。

Google公式の Windows版 Platform-Tools を展開し、以下のファイルを `platform-tools` フォルダへ配置してください。

```text
platform-tools/
├─ adb.exe
├─ AdbWinApi.dll
└─ AdbWinUsbApi.dll
```

## 使い方

1. Android端末でUSBデバッグを有効化します。
2. Windows PCにUSB接続します。
3. アプリで `端末検出` を押します。
4. 転送したいファイルをドラッグ&ドロップ、または `ファイル追加` から複数選択します。
5. Android側保存先ディレクトリを入力、またはAndroid側ファイラーから選択します。
6. 生成されたPowerShellコマンドをコピー、または `.ps1` として保存します。
7. PowerShellに貼り付けて実行します。

## Android側ファイラーについて

Android側ファイラーは目視判断用の軽量表示です。

重くならないように、ファイルサイズや更新日時は取得していません。  
基本的に `ls` の結果だけを表示します。

## 日本語ファイル名について

日本語などの非ASCIIファイル名を含むファイルは、ADB環境によってはリモート側ファイル名生成に失敗することがあります。

そのため、このツールでは以下の方式でコマンドを生成します。

```text
1. ASCII安全な一時ファイル名で adb push
2. push成功後、adb shell mv で元の日本語ファイル名へ変更
```

これにより、ADBのリモート側ファイル名生成失敗を回避しつつ、日本語ファイル名の維持を狙います。

## 注意

- このツール自体は転送を実行しません。
- 生成されたPowerShellコマンドを利用者が確認してから実行する前提です。
- Android側の `mv` が日本語ファイル名を扱えない環境では、リネームに失敗する場合があります。
- その場合、一時ファイル名のままAndroid側に残ります。
- 複数端末接続時はDeviceを選択してください。
- Deviceが空欄の場合、`-s` なしのADBコマンドを生成します。
